# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [CalVer](https://calver.org/) (`YYYY.MM.MICRO`).

## 2026.06.0 — 2026-06-01

### Added

- Dual-pane TUI file browser (local ↔ Android)
- ADB-powered Android filesystem access (no MTP)
- File operations: copy, delete, rename, create folders
- Async transfer queue with progress indication
- Vim-style keyboard navigation
- Bookmarks / favorites
- CLI argument parsing (clap)
- Configuration file support (TOML)
- Tar-streaming for faster directory transfers
